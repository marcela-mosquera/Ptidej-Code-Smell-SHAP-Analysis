# SHAP Analysis of Code Smell Detection Using Ptidej

Reproducibility materials for the study **Beyond Predictive Performance: SHAP-Based Explanations and Alignment with Literature-Based Indicators in Code Smell Detection**.

The notebook examines SHAP-based feature importance, persistence across folds, consistency across software systems, agreement with point-biserial associations, and correspondence with literature-based code smell indicators.

## Experimental setting

- **Software systems:** Azureus, ArgoUML, and Xerces.
- **Code smells:** God Class (GC; labeled `BLOB` in the source data), Functional Decomposition (FD), Swiss Army Knife (SAK), and Spaghetti Code (SC).
- **Models:** 120 SVM models (3 systems × 4 smells × 10 folds), reconstructed using previously selected hyperparameters.
- **Representation:** 50 class-level structural metrics.
- **Explanations:** SHAP applied to the SVM decision function; Test instances are explained using backgrounds drawn from Training data.

## Dataset

The original Ptidej replication dataset is available at:

https://ptidej.net/downloads/replications/wcre12a/

Download the original experimental archive, `OnlineExperimentsData.rar`. The notebook expects the `10-FoldCrossValidationIntraSystem` data, including the original Training01, Training02, and Test partitions. The dataset is not redistributed in this repository.

## Running the notebook

1. Open `Ptidej_Code_Smell_SHAP_Analysis.ipynb` in Google Colab.
2. Upload `OnlineExperimentsData.rar` to the root of your Google Drive (`MyDrive`), or change `RAR_PATH` in the configuration cell.
3. Review the configured paths:

   ```python
   RAR_PATH = Path("/content/drive/MyDrive/OnlineExperimentsData.rar")
   BASE_DIR = Path("/content/raw_maiga/OnlineExperimentsData/10-FoldCrossValidationIntraSystem")
   OUTPUT_DIR = Path("/content/drive/MyDrive/CodeSmells_XAI_Ptidej_v1_5")
   ```

4. Select **Runtime → Run all**. The notebook mounts Google Drive and extracts the archive into the Colab runtime if the data directory is not already present.

The notebook installs `shap==0.52.0` in its initial setup cell. Other Python dependencies are listed in `requirements.txt`. If running outside Colab, install them with `pip install -r requirements.txt`; the Google Drive mounting and archive-extraction cells are Colab-specific.

### Restarting or reproducing a run

Intermediate results are stored under `OUTPUT_DIR/fold_runs/`. On subsequent runs, the notebook can skip completed system–smell–fold combinations when the stored files match the protocol fingerprint. To recompute from the original data, use a **new, empty output directory** by changing `OUTPUT_DIR` before running all cells. This avoids reusing saved fold results.

The original partitions and SVM hyperparameter configurations are preserved. No new hyperparameter search is performed.

## Outputs

The notebook writes experimental results into `OUTPUT_DIR`, including:

- `performance.csv` and `baseline_reproduction.csv`: predictive results and reconstruction checks.
- `shap_global.csv`, `shap_by_fold_normalized.csv`, and `cross_project_consistency.csv`: feature importance, persistence, and consistency across systems.
- `correlation_by_fold.csv` and `shap_correlation_concordance_summary.csv`: marginal association and ranking concordance.
- `literature_operationalizations.csv`, `literature_rule_indicator_coverage.csv`, and `literature_direction_indicator_summary.csv`: operationalizations and literature alignment.
- `shap_sensitivity_pairwise.csv` and related sensitivity summaries: agreement across repeated SHAP realizations.
- `protocol_config.json` and `runtime_versions.json`: analysis settings and recorded software versions.

Publication figures are displayed in the notebook and saved as high-resolution PNG files under `OUTPUT_DIR/publication/figures/`. Publication tables are saved as CSV files under `OUTPUT_DIR/publication/tables/`. The methodological workflow illustration from the paper is not generated by the notebook.

## Reproducibility scope

The main analyses compare model attributions with metric–label associations and published structural indicators. The supplementary sensitivity experiment uses three SHAP realizations for fold 1 of each system–smell combination; it does not test robustness across different model configurations.
